## Context

见 `proposal.md`。现有 TimeIndex 在导入存储模块时会创建默认数据库目录，守护进程会直接连接默认存储；配置优先从用户主目录读取。采集器读取当前 Windows 桌面的可见窗口和系统进程事件，因此在普通桌面上运行真实采集无法隔离私人窗口。当前查询接口有时间、标签与语义查询，闲时整理会写回摘要、标签和聚类编号。实验在白名单源码副本中调用这些真实路径。2026-09-30 用户授权修复产品代码中由实验确认的缺陷，后续实验记录新源码校验值。

## Goals / Non-Goals

**Goals:**

- 在本地网页中配置、批量运行、取消和查看实验；所有评分由保存的标准答案与规则自动得出。
- 将合成实验和专用虚拟机中的真实采集分开报告，使实验可复算、可追踪。
- 保留整个测试流程的 Python 脚本、样本、评分规则和运行清单；报告中明示未测项目。

**Non-Goals:**

- 不把测试平台做成 TimeIndex 的新服务或修改其生产 CLI、数据库结构。
- 不在用户日常桌面自动采集，也不自动创建或配置 Hyper-V 虚拟机。
- 不用另一个模型裁判来替代人工标准答案，不宣称规则评分覆盖所有语义错误。
- 不把虚拟机内的资源数据当作宿主机实测数据，也不与未同机实测的其他产品作定量比较。

## Decisions

### 1. 平台结构与隔离

使用 `test_platform` 内的 Python 批量运行器、固定数据集、评分器和 Streamlit 本地网页。网页只负责参数、状态与结果展示；耗时实验在独立子进程执行，逐步写入状态文件，防止网页刷新打断任务。进程环境变量将 `PYTHONPATH` 指向该轮白名单复制的 TimeIndex 源码，并将 `USERPROFILE` 指向该轮专用用户目录；启动时核验实际导入路径、配置路径和默认数据库路径均位于该轮目录内。复制时排除已有 `.lancedb`、缓存与日志。原源码不打补丁；保留准备、运行、停止和清理脚本。

每轮目录包含不可复用的运行标识、清单、逐例结果、原始审计材料和报告。结束时先保存数据库与评分所需证据，再清理临时源码副本；清理脚本仅接受已核验位于该轮目录下的目标。相比直接复用已安装的 `ti` 命令，这能避免其全局存储路径污染日常数据。相比临时修改原源码，副本机制没有恢复失败后遗留补丁的风险。

### 2. 数据集与执行模式

数据集采用带版本的 JSON/JSONL 清单：每个场景有稳定 ID、快照或桌面动作、预期事件、关键事实及同义表达、标签、分组、相关检索问题和虚构敏感串。完整集预置 60 条合成场景与 30 个检索问题；快速集取固定子集；自定义集沿用同一格式并在执行前校验。随机生成只用于可控变体，记录种子。模型输出可能波动，因此“可复现”指输入、环境与评分可复查，不保证再次推理逐字相同。

合成路径在隔离子进程中构造 TimeIndex 的真实快照类型，调用真实推理、嵌入、记录构建、写库、整理和查询代码。模型不可用时另设明确的故障场景，正常模型质量指标标记未测。真实桌面路径在专用 Windows 测试电脑或虚拟机执行：每轮依次打开、聚焦、观察、关闭记事本、PowerShell 和 Edge/Chrome 的本地测试文档，三轮共九次软件启动尝试；黑名单探针另列。实际启动 PID、窗口、时间、错误与源采集证据均保存。未安装软件不替换为模拟窗口。独立 desktop 模式不构造合成记录，实际 WMI/推理/整理/检索使用单独数据库。采集沿用默认五秒及核心黑名单，采集结束后手动调用核心整理函数，自动闲时触发明确未测。共用桌面无法保证只看到测试窗口，网页要求确认专用测试桌面并记录条件。

### 3. 自动评分口径

评分器从保存的逐例结果重新计算聚合指标。事件按类型、测试进程标识及场景时间窗做一对一匹配；窗口按唯一测试标题与时间窗匹配。未匹配的预期项为漏记，额外项为误记，同一预期项的额外匹配为重复。延迟用场景动作时间到首条对应入库记录时间计算；没有样本的指标显示未测而非零。

文本先做 Unicode 规范化和大小写归一，再按数据集中列明的等价表达匹配事实；不使用临时生成的同义词。标签计算微平均准确率、召回率和 F1；聚类按“任意两条记录是否同组”计算成对 F1，无法评价的单例集显示未测。重整理前后使用相同记录和事实答案。检索对照使用同一数据库快照，语义查询调用原接口，关键词对照在摘要文本上作确定性匹配，标签对照使用预设标签；按相关 ID 集合计算 Hit@1、Hit@5、MRR@5。逐题保存排序结果与耗时。

### 4. 隐私与资源边界

隐私数据集只使用虚构标识。受控代理在不改变模型返回值的前提下记录聊天和嵌入请求的输入，结合采集快照、数据库及报告逐阶段检查虚构串；再检查进程黑名单、窗口标题、字段结构和接口地址。模型请求默认仅允许回环地址。为了在另一台电脑运行合成实验，实验者可显式允许私有局域网 IP；此时只发送虚构合成样本，报告记录跨设备条件，并将另一台电脑的模型资源标为未测。专用虚拟机的真实桌面采集仍只允许回环模型地址；其他非回环地址在发送审计样本前被拒绝。原始材料只留在该轮目录，默认 HTML/CSV 导出使用一致的替换表脱敏，并对导出文件再次扫描。报告展示暴露面，不汇总成“隐私安全分数”。

资源测量默认关闭。开启时按固定间隔分别采集 TimeIndex 进程树与可定位的模型进程树的 CPU 和常驻内存，同时记录数据库大小、处理和查询时延、虚拟机 CPU/内存配置。报告同时保留基线与活动时段，不把无法定位或运行于宿主机的模型资源估算为零。GPU 只有在本机测量接口可用时才单独显示，不作为完成条件。

### 5. 结果与启动方式

平台使用独立依赖清单和锁定版本，提供 Windows 环境检查与启动脚本。网页绑定 `127.0.0.1`；一轮只允许一个活跃实验。输出包括原始逐例 JSON、可复算汇总 JSON、脱敏 CSV 和自包含 HTML。运行清单记录源码校验值、数据集版本、随机种子、Python/Windows/硬件信息、模型与嵌入模型、开始结束时间、项目状态和未测原因。取消时先请求子进程有序停止，超时后仅终止本轮进程树，保留已完成证据。

已结束的实验另提供一键诊断 ZIP 和 `bundle` 命令。按固定文件清单只读取现有报告、运行清单、数据集及诊断 JSON，沿用脱敏规则并沿用已有报告的敏感标记编号；文件校验值和缺失项目写入包清单。失败启动没有正式报告时仍保留错误与环境检查材料。配置、令牌字段、请求头、日志和数据库不打包，不重新推理或重算原实验。网页按文件修改时间与大小缓存压缩结果，避免每两秒刷新重新压缩；打包期间材料变化则要求重试。非测试标题按每层字符串处理，保留嵌套 JSON 的合法结构。

## Risks / Trade-offs

- [模型响应不稳定] → 保存每次实际响应及版本，固定答案与评分规则，允许只重算指标而不重新推理。
- [窗口枚举包含虚拟机内的其他窗口] → 只在专用虚拟机批测，使用唯一标题匹配，并把额外窗口作为环境噪声记录。
- [默认数据库或用户配置路径误指向生产位置] → 子进程启动前后核验解析后的绝对路径；核验失败立即中止，不运行实验。
- [Streamlit 页面刷新与子进程生命周期不同步] → 以运行清单和进程标识为准，恢复页面时读取磁盘状态，不在网页进程内执行模型调用。
- [规则评分误判灵活摘要] → 同义表达预先列入数据集，保留逐例证据与“规则未评估”状态，不把分数解释为完整语义正确率。
- [资源归属不完整] → 分开报告进程数据及未测原因，明确虚拟机与宿主机边界。

## Migration Plan

### 2026-10-04 论文实验方案

增加 paper 模式与独立 paper-1.0 清单：60个场景、6类活动/12个主题、12个主题查询、18个指定记录查询、6个实际输入时间范围。主指标覆盖记录、整理前后主题/自由标签线索、主题回忆、完整时间集合及隐私，精细章节、固定词表和分组仍作为诊断。评分版本4.0标明新增任务与报告口径，旧公式保留；重算另保留原评分版本。

四种检索方法使用同一真实入库集合。主题问题预先接受该主题五条记录，指定问题只接受目标一条；原始标题和摘要关键词方法使用同一套预先给定关键词，指定问题包含章节。时间查询由输入安排确定正确集合和实际快照边界，调用核心时间接口，不依赖返回结果生成答案。质量指标、调用完成率、错误和未测同时报告。

新增论文主表、检索分任务表、时间查询表和隐私阶段表，HTML说明方法/数据/结果，ZIP带出新增文件。论文模式可附加原真实软件与黑名单阶段，仍要求专用桌面及本机模型；私有局域网还必须明确标为虚构数据。没有修改TimeIndex提示词、模型输出或原源码。真实桌面、长期运行、自动闲时触发和OpenClaw端到端不能由合成成绩替代。

本变更新增 `test_platform` 内容，并在 2026-09-30 修复中修改 TimeIndex 的存储与模型处理代码，无现有数据迁移。部署时安装平台依赖并运行环境检查；撤销时停止测试子进程、清理各轮临时副本并移除平台文件；如需回退产品修复，应同时恢复上述两个 TimeIndex 源文件，日常数据库不需要迁移。

### 2026-09-30 验收修复

整理更新先与已有记录合并，再原子写回，保留检索向量、原始窗口和硬件字段；Pandas 空值转为真正的空值。模型提示词仅要求依据实际日志保留主题、编号和应用，不提供可能被照抄的具体应用示例。整理响应只接受 ID 匹配且全部字段有效的记录，缺失项保持待整理。平台按每批四条执行并保存批次证据，逐例核验完整率与整理前后向量。规则评分版本 `2.0` 使用同批分母，另列共同完成样本的前后比较。旧结果重算保留原始证据、源码校验值与原始查询结果，但用新的分析代码校验值标明重算规则；无效或未核验的向量不产生语义质量分数。

### 2026-10-02 核心功能与透明报告修订

当前评分规则 `3.0`、默认数据集 `2.0`。快速集跨六类主题，完整集保持60条/30题。标准答案只依赖 TimeIndex 可见的标题、进程和章节线索，不把虚构的编辑行为/文档正文当成已观察事实。自由标签按预先列明的可接受线索统计覆盖，固定词表F1作为诊断。整理采用核心默认批次20条，分组成对评分只比较同批记录，跨批同名分组不自动视为同组。真实桌面质量标准答案仅从实际推理请求中出现的受控窗口产生，避免把未进入核心提示词的窗口也算作遗漏。原始窗口、事件和时间是否原样入库单列。

旁路代理保存每次SDK调用的实际参数、完整系统/用户消息、原始响应、reasoning_content、用量、完成原因、时间和错误；不更改核心输入/输出，请求头和访问令牌不取证。证据写入失败不影响原接口结果，但整体标为部分完成。记录、批次、查询ID关联调用ID。HTML离线展示软件清单、动作时间线、逐例输入、初始与整理原文、模型请求/原文、每题实际参数与排序记录。完整向量回复在折叠区和明细JSON；旧证据缺失原文明确说明且不补造。快速检索展示库大小与随机前五命中的理论参考，不能据此宣称长期检索质量。

默认导出保留受控虚构输入、遮罩审计串及非测试窗口标题；原始材料仅本地留存。资源仍为可选，工作进程含TimeIndex与取证开销，剔除被打开的业务软件子进程；CPU使用连续同一进程计数器，磁盘统计本轮两个活动数据库。
